# 🎬 Netflix Clone

Clone da interface da **Netflix**, desenvolvido com **React.js + TypeScript**, com objetivo de aprendizado em front-end moderno e boas práticas de componentização.

## 🚀 Tecnologias Utilizadas

- ⚛ **React.js** com **TypeScript**
- 🎨 **CSS/Sass** para estilização
- 🛠 **ESLint** para padronização do código
- 🌐 Integração com **API de filmes/séries** (ex.: TMDB)

---

## ✨ Funcionalidades

- Página inicial com design inspirado na Netflix
- Carrosséis de filmes/séries por categoria
- Banner de destaque
- Modal para exibir detalhes de títulos
- Layout responsivo (desktop/tablet/mobile)
